This section covers the Develop and Test phase: building agents in WSO2 Agent Builder before anything ships. We assume you're already familiar with the editor from the [Editor Tour](../editor/index.mdx).

:::tip
Start by describing what your agent should do to [WSO2 Agent Builder Copilot](../editor/copilot/copilot.mdx) on an empty agentic integration's overview. Copilot generates a first working version, which you can refine on the visual designer, and drop into Ballerina code only when you need more precise control. Everything stays in sync throughout.
:::
