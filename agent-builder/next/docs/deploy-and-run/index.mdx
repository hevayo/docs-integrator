Once your agent works in Choreo Agent Builder, this section covers how to ship it and how to run it in production.

You deploy from the **Deploy** panel on an agentic integration's overview, or from the **Deploy** menu on the project overview.

## Deploy

Choose where your agents run. Where you deploy also decides how you [manage](../manage/index.mdx) and [observe](../observe/index.mdx) them.


### Deploy to Choreo Agent Manager

- Run and manage your organization's agents in one place
- Connect to your Agent Manager instance
- Builds from your GitHub repository

[Deploy to Choreo Agent Manager →](./deploy-to-choreo-agent-manager/index.mdx)


### Deploy to Choreo Cloud

- Fully managed, with no infrastructure to set up
- Deploy one agentic integration or a whole project
- Builds from your Git repository

[Deploy to Choreo Cloud →](./deploy-to-choreo-cloud/index.mdx)


### Self-Hosted Deployment

Run integrations on infrastructure you manage.

- [Containers](./self-hosted/containerized-deployment.mdx)
- [Virtual machines](./self-hosted/vm-deployment.mdx)
- [Serverless](./self-hosted/serverless-deployment.mdx)
- [GraalVM native images](./self-hosted/graalvm-native-images.mdx)
