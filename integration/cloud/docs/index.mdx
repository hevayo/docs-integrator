[Let's get started](./get-started/index.mdx) · [Platform overview](./platform-overview/index.mdx)

No installation: it runs in your browser.

## New to Choreo Cloud?

Build your first integration in four steps, starting with a quickstart: [set up](./get-started/setup/index.mdx), pick a quickstart below, design the flow on the canvas or with Copilot, then run and deploy it straight from the cloud. The [key concepts](./get-started/concepts/index.mdx) explain the terms.
