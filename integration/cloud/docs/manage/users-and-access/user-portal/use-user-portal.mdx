After you [sign in to the User Portal](./sign-in-to-user-portal.mdx), you see the integrations that your organization published to you. Your roles decide which integrations you see and what you can do with them. If you do not see an integration that you expect, or a button is disabled, contact your organization's administrator. See [Scopes](./manage-users.mdx#scopes). This page explains how to find an integration and how to use each type:

- [Chat with an AI agent](#chat-with-an-ai-agent)
- [Run an automation](#run-an-automation)

## Find an integration

The **Overview** page shows the integrations published to you under **Your Integrations**. To see the integrations of one type, in the left navigation menu, under **Integrations**, click **AI Agents** or **Automations**.

![Overview page of the User Portal with an automation under Your Integrations](../../../../assets/img/manage/cloud/user-portal/integration-list.png)

## Chat with an AI agent

On the **Integrations** tab, find the AI agent and click **Chat**. The chat panel opens on the right, where you can send messages to the agent.

![Chat panel in the User Portal with a conversation with an AI agent](../../../../assets/img/manage/cloud/user-portal/agent-chat.png)

## Run an automation

1. Click the automation on the **Overview** page or the **Automations** page.

    The automation page shows whether the automation runs on a schedule, and its **Runs**.

2. If the automation takes runtime arguments, the page shows a form. Enter a value for each field. Required fields are marked with an asterisk (`*`).

    ![Automation panel in the User Portal with a form for the automation's runtime arguments](../../../../assets/img/manage/cloud/user-portal/automation-form.png)

3. Click **Run**.

The run appears under **Runs**, with its status, start time, duration, and run ID.

![Automation page in the User Portal with the Run button and a succeeded run under Runs](../../../../assets/img/manage/cloud/user-portal/automation-run.png)
