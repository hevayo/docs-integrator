Every AI feature in Choreo Integrator, direct LLM calls, agents, and natural functions, is composed from the same small set of shared connections. Configure one once, then reuse it wherever it's needed.


### Model Providers

Connect to the LLM behind every prompt: the Default WSO2 provider, OpenAI, Azure OpenAI, Anthropic, Google Vertex, Mistral, DeepSeek, Ollama, and OpenRouter.
